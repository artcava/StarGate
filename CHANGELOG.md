# Changelog

All notable changes to StarGate will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-02-27

### Added
- Initial release of StarGate
- Core API functionality and project structure
- Comprehensive documentation:
  - Git-Flow workflow guidelines
  - Coding conventions and standards
  - Pull request process
  - Release process documentation
- Development environment setup:
  - Docker Compose configuration
  - EditorConfig for consistent code formatting
  - Environment configuration templates
- Project solution structure with proper organization
- Build configuration and properties
- Testing infrastructure

### Dependencies
- .NET 8.0 runtime and SDK
- Target framework: net8.0
- Language version: latest C# features
- Nullable reference types enabled
- Implicit usings enabled
